## 開発記録

- 開発・改善記録（DEVELOPMENT_LOG.md）

## 概要

販売価格・原価・数量・税率を入力して、売上や利益を計算するWebアプリです。

プログラミングを学ぶだけでなく、自分で動くものを作りながら理解を深めたいと思い、開発しました。

## 主な機能

- 売上・原価・利益・利益率の自動計算
- 税率の切り替え（10％・8％・税なし）
- 入力内容の保存・復元
- 計算結果のコピー、入力内容のクリア

## 使用技術

HTML / CSS / JavaScript / LocalStorage

GitHubでソースコードを管理し、GitHub Pagesで公開しています。

## 開発で取り組んだこと

開発中は、エラーが出たときに原因や修正箇所を確認し、修正後に実際に動かして確かめることを意識しました。

また、計算するだけでなく、入力内容の保存や復元、操作結果の表示など、使う人にとって便利な機能も追加しました。

## 不具合対応・改善記録

開発中には、保存・復元がうまく動作しない問題や、ボタンを押しても反応しない問題に対応しました。また、スマートフォンでのメッセージ表示も改善しました。

コードを修正した後は、実際に操作して動作を確認しながら改善を進めました。

この経験から、機能を実装するだけでなく、利用者が問題なく操作できるかを確認することの大切さを学びました。

今後は、不具合の内容や修正内容、テスト結果を記録し、問題の原因を整理して再発防止につなげられるよう取り組んでいきます。
